> 本文档面向接手本项目继续开发的开发者。请先通读全文（尤其「硬性约束」与「常见坑」），再动手。

## 1. 项目概况

**智简灵析** 是面向**基层政务**的 AI 智能自动化系统，专为街道办、社区等基层单位打造的数字员工，集**自动执行 + 智能风控 + 隐私合规**于一体。

核心能力：
- 自然语言建任务（口语描述 → 规则 JSON，支持多轮精炼）
- 操作录制（录一遍真实操作 → 生成规则）
- 页面改版自动重定位（四层智能自愈）
- 读取/清洗/总结多格式数据（Excel / CSV / PDF 含扫描件 OCR）
- 导出报表（csv/json/xlsx/docx/pdf，支持模板填充）
- 合规三件套：PII 脱敏网关 + 人工审核队列 + 操作审计日志

**AI 风险原则**：为避免 AI 黑盒决策风险，设置严格权限隔离与人工兜底机制——高危动作与敏感数据经**人工二次确认**才放行，全程留痕可追溯。**AI 辅助、人来把关。**

## 5. 快速上手

### 5.1 后端

```bash
cd zhijian-lingxi/backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 可选：安装内置浏览器（仅内置模式需要；打包版/接管模式无需）
playwright install chromium

# 启动（⚠️ 严禁 --reload，见第 6 节）
python -m uvicorn main:app --port 8710
```

### 5.2 前端

```bash
cd zhijian-lingxi/frontend
npm install --registry=https://registry.npmmirror.com
npm run dev        # 开发服务器 http://localhost:5173
```

### 5.3 首次使用

1. 设置页配置 **API Key**（智谱 AI 免费推荐 / 硅基流动免费），否则 LLM 功能（自然语言建任务、AI 总结、OCR）不可用
2. 浏览器模式默认「**接管我的浏览器**」——需先用调试参数打开浏览器：

```bash
msedge.exe --remote-debugging-port=9222 --user-data-dir="C:\edge-profile"
```

3. 纯文本/表格类功能（read_excel/read_csv/read_pdf文本/录制/导出）**不依赖 LLM**，不配 Key 也能用

## 6. 硬性约束（违反必踩坑）

1. **后端严禁 `--reload`**：Windows 下 `--reload` 强制 SelectorEventLoop，Playwright 子进程直接 `NotImplementedError`，任务 steps=0 失败。
2. **Chromium 用户目录必须纯英文路径**：中文路径启动即崩溃。
3. **接管模式执行完不关浏览器**：浏览器归用户所有（登录态在其中），任务结束只断连接，保留登录态供复用。
4. **新增动作需同步改动 4 处**：`models.py`（类型+字段）、`rule_engine.py`（schema 白名单）、`nl_parser.py`（提示词）、`RuleEditor.vue`（下拉+表单）+ `types/index.ts`（TS 类型）+ 动作中文标签映射（RuleCard/StepTimeline/Instruction）。
5. **前端别名 `@/*` 双配置**：改路径别名需同时改 `tsconfig.json` 与 `vite.config.ts`。
6. **打包版无内置浏览器**：`browser_mode` 默认 `attach`，录制/执行都走接管；录制器与执行器一样读该设置，不能硬编码 `chromium.launch`。

## 7. 关键设计速览（详见 Code-Wiki.md）

### 7.1 四层智能自愈（元素定位降级）

文本精确定位 → 位置序号定位 → ①CSS 选择器 ②语义模糊匹配 ③AI DOM 分析 ④视觉定位（截图+坐标），每层验证失败才降级；低信任点击主动视觉复核。

### 7.2 OCR 方案

**多模态大模型读图**（非 PaddleOCR/Tesseract）。三个入口：`ocr`（网页截图识别）、`ocr_to_json`（截图→结构化表格）、`read_pdf` 扫描件（PDF 渲染成图 → OCR）。OCR 结果接入 PII 脱敏网关。

### 7.3 PII 脱敏网关

可逆掩码（明文→`@MASK_n@`占位符→LLM→还原），只在单次 LLM 调用局部成对出现，外部永远存明文。内置身份证/手机/银行卡/邮箱/车牌/座机正则 + 姓名整值占位。

### 7.4 数据流水线

`read_pdf/read_excel/read_csv → data_clean → llm_summarize → export`，`__table` 变量串联步骤。

## 9. 打包发布

完整流程、分发布局、已知坑见 README「打包桌面应用」章节。要点：

```bash
# 后端（无窗口）
cd backend && pyinstaller --onefile --noconsole --name 智简灵析后端 --clean main.py

# 前端 + 壳
cd frontend && npm run build && npm run tauri build
```

分发布局（壳自动拉起后端、退出自动清理）：

```
publish/
├── zhijian-lingxi.exe
└── backend/智简灵析后端.exe
```

**已知打包坑**：`tauri` 无 `notification-all` feature；`tauri.conf.json` 的 `plugins.notification` 必须为 `null`；手动 `cargo build` 必须带 `--features custom-protocol`，否则窗口显示「无法访问此页面」。`--noconsole` 下日志重定向到 `data/logs/backend.log`。
